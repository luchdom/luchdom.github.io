# luchdom.com

Personal vCard site for Lucas Domingues, served by GitHub Pages.

## Development

Edit the readable source at `src/index.html`. Alternate draft pages are kept in `src/` so the repository root stays focused on published assets.

Build the minified page served by GitHub Pages:

```sh
npm install
npm run build
```

The generated `index.html` is committed intentionally so GitHub Pages can serve it as a static file.
